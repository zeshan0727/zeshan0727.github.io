Double-tap a genuinely empty area of the Home Screen to lock your iPhone.

Version 1.0.3 · RootHide + Rootless · iOS 15+

Version 1.0.3 Diagnostics

Adds a Settings pane that confirms package version, SpringBoard injection, root-folder hook, gesture attachment, last touch decision, last gesture result and lock route.

Test Lock Now

Open Settings → Next Home Lock and press Test Lock Now. This sends a direct diagnostic command to the injected SpringBoard tweak. If the phone locks, injection and the lock route are working independently of the Home Screen gesture.

Privacy

Diagnostics are stored locally. No daemon, analytics, clipboard access, messages, account data or network activity.

Test sequence

  1. Refresh the repo and confirm Sileo shows version 1.0.3.
  2. Upgrade the matching package and respring.
  3. Open Settings → Next Home Lock.
  4. Record the Injection, Root Folder Hook and Gesture Attachment values.
  5. Press Test Lock Now, then test the Home Screen double-tap.
  6. Return to Settings and press Refresh Diagnostics.
